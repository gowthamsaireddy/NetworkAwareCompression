# Experiment Records & Artifacts

This directory stores reproducible experiment logs generated by the sender and receiver applications.

## Formats
- `experiments.sqlite`: Persistent relational SQLite database of transmission trials and segmentation benchmarks.
- `experiments.csv`: Tabular export containing all metrics.

## Zero-Dummy Policy
- Experimental records are only recorded during real network trials.
- Never manually insert mock numbers or fabricated metrics into this directory.
